# Project 1: Campus Resource Reservation System
By Blair Rush, Eddie Najera, and Evan Christensen

## Project Overview
This program is designed to read in pre-existing reservations and resources from a file, and manage them
along side creating and managing new reservations. The reservations are for on-campus resources that
students can check out and reserve on a specific date.

## User Guide
When the program is first launched, the program will automatically load in the files and fill out the 
pre-existing reservations and resources, so the user doesn't have to worry about that.

The user will be presented with a list of options, each with a corrosponding number, type the number then
press enter to choose that option, and the program will guide you from there.

If you want to exit the program, enter 0 in at the option select screen.
